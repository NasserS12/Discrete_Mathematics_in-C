# Discrete Mathematics in C

A repository containing solutions to problems and equations from the Discrete Mathematics course, implemented in C.

## About

This repository applies discrete mathematics concepts practically by solving them using C code.

## Topics Covered

- Propositional Logic
- Set Theory
- Functions and Relations
- Combinatorics (Permutations and Combinations)
- Number Theory (GCD, Prime Numbers, etc.)
- Matrices
- Graph Theory
- Mathematical Induction

## How to Run

```bash
gcc filename.c -o output
./output

Example:

```bash
gcc truth_tables.c -o truth_tables
./truth_tables
```

## File Structure

Each `.c` file solves a single problem, with the filename reflecting its topic.

```
discrete-mathematics-in-c
 |-- logic.c
 |-- gcd.c
 |-- permutations.c
 |-- ...
 |-- README.md
```
