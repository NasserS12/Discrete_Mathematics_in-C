# Discrete Mathematics in C

A repository containing solutions to problems and equations from the **Discrete Mathematics** course, implemented and solved using the **C** programming language.

## 📌 About

The goal of this repository is to apply the theoretical concepts of discrete mathematics practically by implementing them in C, reinforcing understanding through code.

## 📂 Contents

This repository includes solutions for topics such as:

- Propositional Logic
- Set Theory
- Functions & Relations
- Combinatorics (Permutations & Combinations)
- Number Theory (GCD, Prime Numbers, etc.)
- Matrices
- Graph Theory
- Mathematical Induction

> This list will be updated as new topics are added.

## ⚙️ How to Run

To compile and run any file in this repository, use:

```bash
gcc filename.c -o output
./output
```

Example:

```bash
gcc gcd.c -o gcd
./gcd
```

## 🗂️ File Structure

Each `.c` file represents the solution to a single problem or equation, with the filename reflecting the topic it solves.

```
📁 discrete-mathematics-in-c
 ├── logic.c
 ├── gcd.c
 ├── permutations.c
 ├── ...
 └── README.md
```

- Reinforce theoretical concepts through practical implementation.
- Build a personal reference of solved problems for the course.
- Improve C programming skills while studying discrete mathematics.
